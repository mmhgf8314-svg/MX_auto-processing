# MX_auto-processing

Matrox（MX）関連の顧客・パートナーを対象にした CRM 自動化。

「誰に・いつ・どのようなアクションをしたか・今どうなっているか」を Notion の台帳で一元管理し、
Gmail の実際のやり取りから最終接点日を自動更新して、**1ヶ月に一度すべての取引先をフォローアップする**ための仕組み。

## 構成

| 場所 | 役割 |
| --- | --- |
| Notion `MX_CRM 顧客・接点管理` | 台帳そのもの。人が見て・書く場所 |
| このリポジトリ（Google Apps Script） | Gmail から最終接点日を自動更新し、月次のフォロー漏れを検出する |

Notion 台帳: Business > MX > **MX_CRM 顧客・接点管理**
（データベース ID: `dd6c84a357164dd9a7075358a4cff9a5`）

### ビュー

| ビュー | 用途 |
| --- | --- |
| 既定のテーブル | 全件一覧 |
| 🔴 要フォロー（30日以上未接触） | 月次フォローアップの作業リスト。放置が長い順 |
| ステータス別ボード | 商談の進み具合を俯瞰する |
| フォロー予定カレンダー | 「次回フォロー予定日」を月カレンダーで見る |
| ⭐ 重点顧客（A） | 優先度 A だけを追う |

### 主なプロパティ

- **最終接点日 / 最終アクション** … 誰に・いつ・何をしたか（Gmail から自動更新）
- **ステータス** … リード / 初回接触 / 商談・提案中 / 評価・PoC中 / 受注・納入 / 保留・様子見 / クローズ
- **次のアクション / 次回フォロー予定日** … 手で書く。自動更新では上書きしない
- **経過日数 / 要フォロー** … 数式。30日以上で 🔴、21日以上で 🟡

## スクリプトの中身

| ファイル | 内容 |
| --- | --- |
| `src/Config.gs` | 設定（Notion DB ID、自分のアドレス、社内ドメイン、フォロー間隔など） |
| `src/Notion.gs` | Notion API の読み書き |
| `src/GmailScan.gs` | Gmail を走査して最終接点日・最終アクションを更新 |
| `src/Followup.gs` | 月次フォローアップ（ダイジェスト送信＋下書き作成） |
| `src/Triggers.gs` | トリガー設置と、書き込みなしの動作確認 `dryRunSync` |

## セットアップ

1. **Notion インテグレーションを作る**
   - <https://www.notion.so/my-integrations> で内部インテグレーションを作成しトークンを控える
   - Notion 側で `MX_CRM 顧客・接点管理` を開き、`···` > `接続` から作ったインテグレーションを追加する

2. **Apps Script プロジェクトを作る**
   - <https://script.google.com> で新規プロジェクトを作り、`src/` 配下の `.gs` を貼り付ける
   - `appsscript.json` の内容も反映する（プロジェクトの設定で「マニフェスト ファイルをエディタで表示」をオンにする）

3. **トークンを登録する**
   - プロジェクトの設定 > スクリプト プロパティ に `NOTION_TOKEN` を追加し、1 のトークンを入れる
   - トークンはソースには書かない

4. **動作確認する**
   - `dryRunSync` を実行し、実行ログで「何が更新される予定か」を確認する（Notion には書き込まない）
   - 問題なければ `syncLastContactFromGmail` を1回手で実行する

5. **トリガーを設置する**
   - `setUpTriggers` を1回実行する
   - 毎日 07 時台に Gmail 同期、毎月 1 日 08 時台に月次フォローアップが走る

## 運用

毎月1日に届くダイジェストメールが作業リストになる。

1. ダイジェスト（またはNotionの「🔴 要フォロー」ビュー）を開く
2. 優先度 A / B は Gmail の下書きが自動で作られているので、内容を直して送る
3. 送ったら翌朝の同期で最終接点日が自動で入る
4. オンライン会議など**メール以外の接点**は、Notion 側で最終接点日と最終アクションを手で更新する
   （手入力の日付が Gmail より新しい場合、自動同期は上書きしない）

## 注意

- 自動同期が触るのは **最終接点日 / 最終アクション / 次回フォロー予定日** の3つだけ。
  ステータスと「次のアクション」は人が判断して書く欄なので、スクリプトは変更しない。
- `CONFIG.INTERNAL_DOMAINS`（Matrox 本社など）は接点としてカウントしない。
- フォロー間隔を変えたい場合は `CONFIG.FOLLOWUP_INTERVAL_DAYS` を変える。
