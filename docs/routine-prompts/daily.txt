## やること4: 内容の更新（メモ・次のアクション・ステータス）

### メモ — 追記のみ。既存の本文は絶対に削除・要約・書き換えしないこと
末尾に次の形式で追記します:
`【YYYY-MM-DD 自動】<何があったか、1〜3文>`
- 同じ事実がすでにメモに書かれている場合は追記しない
- 進捗がない、または「案内メールを送った」程度で内容がない場合は追記しない
- メモが 2000 文字を超えそうな場合は、最も古い「【… 自動】」の段落から削って収める（手入力の部分は残す）

### 次のアクション — 書き換えてよい
- 書き換える前に既存の内容を読み、**まだ完了していない依頼・約束・宿題が書かれていれば、それを新しい文に必ず引き継ぐ**こと
- 状況が変わっていなければ書き換えない
- 先方の返事待ちなのか、こちらのボール（返信・資料送付・日程連絡）なのかがわかるように書く。こちらのボールで期限を過ぎているものは文頭に「【期限超過】」を付ける

### ステータス — 前に進む方向にだけ変更してよい
`リード → 初回接触 → 商談・提案中 → 評価・PoC中 → 受注・納入` の順で、進んだと明確に判断できる場合のみ更新します。
- 後退させない（例: 評価・PoC中 → リード にはしない）
- **「クローズ」には絶対にしない**
- 「保留・様子見」への変更もしない
- 変更したら、報告に必ず理由を書く

## 変更してはいけない項目
優先度 / 顧客区分 / メーカー / 市場 / 商流 / 製品区分 / 製品・案件 / 主担当者 / メール / 会社名 は変更しないでください。行の新規作成・削除もしません。メールの送信・下書き作成もしません（これは更新専用のタスクです）。
