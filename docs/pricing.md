# OEM 製品の価格（JM 向け価格の計算式）

Matrox の OEM 製品（X.mio、DSX LE、M264 など）を JM（ジャパンマテリアル）に見積もるときの計算式と、価格表の使い方。
価格表そのものはリポジトリに置かない。Drive の「Matrox_Price」フォルダにある。

## どのファイルを使うか

| ファイル（Drive） | 位置づけ |
|---|---|
| `OEM_pricelist_April_24_2025_TK.xlsx` | **基準。Matrox の最新の OEM 価格表（2025-04-24 版）**に本人がメモを足したもの。定価は USD／EUR／GBP。型番の英文説明つき。DLE6（100GbE）、X.mio5、DSX LE5（D25L4／D25L44 を含む）、JPEG XS のフィールドアップグレード、LTC キット、Unreal Engine プラグインまで載っている |
| `OEM_pricelist_20260515_TK.xlsx` | JM 向け価格の計算シート。「Price to JM」列に下の式が数式で入っている。ただし品目は古く、DLE6・JPEG XS アップグレード・D25L4 系がなく、逆に 2025 年版から消えた X.mio3 IP／DSX LE4 IP／通常 BNC 版が残っている |
| `OEM_pricelist_Nov25_2021.xlsx` | 旧版。参考のみ |

手順: **定価は 2025-04-24 版で引き、下の式で JM 向け価格を出す。** 20260515 版に載っている型番なら、その「Price to JM」列の値をそのまま使ってよい（同じ式）。

## 計算式

JM 向け価格 ＝ Matrox 定価（USD）× 0.6 ＋ 製品群ごとの固定加算額

| 製品群 | 固定加算額（USD） | 対象の型番 |
|---|---|---|
| X.mio シリーズ | 250 | XMIO5…、XMIO3…、XMIO3L… |
| DSX LE シリーズ | 195 | DLE6…、DLE5…、DSXLE4…、DSXLE4L… |
| M264 シリーズ | 500 | M264…、M264S2…、M264S3…、M264S4… |
| ケーブル類 | 0 | HDBNC/1、AULT…、LTC/KIT |

- 掛け率 0.6 は全製品群で共通。違うのは加算額だけ。
- 加算額は以前は一律 125 だった。製品群別（250／195／500）に変わったのは 20260515 版のメモに書いてある。
- 20260515 版の `DLE5L/4/100` の行だけ式が × 0.7 になっているが、これは無視してよい（本人確認済み、2026-09-25）。すべて × 0.6 で計算する。
- 2025-04-24 版の F 列以降には本人の計算メモが散らばっている（DLE6 と DLE5 2110 の一部に × 0.6 ＋ 195 の式、ほかは試算）。式の根拠はこの文書を優先する。
- JM 向け価格が決まっていない品目: VERO、フィールドアップグレード（コーデック、I/O、JPEG XS）、DSX Core のライセンス、SDK、トレーニング、Unreal Engine プラグイン。見積が要るときは Mingkai に聞く。

## 型番の読み方

- 末尾のクラス: `/100` はソフトウェアコーデックなし、`/500` はコーデックとエフェクト込み、`/550` は `/500` に ProRes を加えたもの。
  `/500` と `/550` は定価が同じ。
- I/O 構成: `/X2`、`/8`、`/4` などは SDI の系統数。`L` は低背（Low Profile）、`B` は通常 BNC、`H` はヒートシンク付き、
  DSX LE4 の末尾 `F` はファンレス版。
- ST 2110 カード: `D25` は 25GbE ×2、`Q25` は 25GbE ×4、`Q25/D` は Q25 のうち 2 ポートだけ有効にした版
  （`UPGIO/D/UQ25` で Q25 に上げられる）。`DLE6D100` は 100GbE ×2（QSFP28）で 4K ×8 入出力。
- JPEG XS のフィールドアップグレード（X.mio5、DSX LE5）: `UPG/JXS{2K|4K|8K}/{G|C}{D|E}`。G は GPU コーデック、C は CPU コーデック、
  D はデコーダ、E はエンコーダで、1 インスタンスごとの価格。
- SFP／QSFP モジュールは VERO、DLE6、X.mio5、DSX LE5 のいずれにも含まれない。
- 型番ごとの英文説明（I/O 構成とコーデックの内訳）は 2025-04-24 版に載っている。

## 価格表の構成（2025-04-24 版）

| シート | 中身 |
|---|---|
| Product Selection | 現行 OEM 製品の定価（USD／EUR／GBP）と説明。これが本体 |
| Private SKUs | 一般公開しない SKU（低背・ヒートシンク版 LE5、GV 専用と Vizrt 専用の DSX Core、ファンレス LE4） |
| Extended Warranty | 延長保証。EW2 はハードウェア販売価格の 15%（VERO は EW1 が 7.5%、EW2 が 15%） |
| EOL | 生産終了品（Mojito、X.mio2、DSX LE3） |

## 注意

- 顧客に出す価格は JM が決める。この式は Matrox から JM への価格で、顧客向けのメールや表には書かない。
- ProRes（`/550`）への切り替えについて、価格表には `UPG/500/U55` が有料で載っている。Apple のライセンス締結後に無償で
  `/500` から `/550` へ上げられるという案内と食い違うので、OEM に無償と伝える前に本社で確認する。
